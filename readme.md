# 编辑器式 Todo Workspace for DocumentApp

  ## Summary

  把当前的 DocumentGroup + SwiftData 模板改造成“一个 document = 一个工作区包”的编辑器应用。每个工作区内包含多个可排序的子文件，窗口
  采用左侧 Sidebar + 右侧工具栏/内容区结构；右侧内容区支持 编辑模式 和 预览模式，默认进入编辑模式。document 重开后需要恢复并自动选
  中上次打开的子文件。

  ## Key Changes

  - 文档边界
      - 保留现有 package 型 document。
      - 一个 .exampledocument 持久化一个工作区，而不是单条 Item。
      - 工作区内持久化多个子文件实体，每个子文件包含 id、title、content、sortOrder、createdAt、updatedAt。
      - 工作区级元数据新增 lastSelectedFileID，用于恢复上次选中的子文件。
  - 数据模型与接口
      - 用 WorkspaceFile 作为主内容模型。
      - 新增工作区级模型或元数据记录，至少包含 lastSelectedFileID。
      - 新增窗口级 UI 状态：selectedFileID、editorMode。
      - 新增仅内存使用的解析层类型，例如 PreviewLine / PreviewLineKind，用于把 content 解析成预览结构并回写文本。
  - 左侧 Sidebar
      - 展示当前工作区内全部子文件，按 sortOrder 排序。
      - 支持新建、删除、重命名、拖拽排序。
      - 新建后自动选中该文件，并立即更新 lastSelectedFileID。
      - 删除当前选中文件后，自动选中相邻文件；同时更新 lastSelectedFileID。若已无文件则清空该字段并显示 empty state。
      - document 打开时优先恢复 lastSelectedFileID 对应文件；若该 ID 不存在，再回退到排序后的第一个文件。
  - 右侧布局
      - 上方固定工具栏，下方是主内容区。
      - 工具栏提供两个互斥模式按钮：编辑、预览；默认 编辑。
      - 模式是窗口级状态，切换子文件时保持当前模式不变；首次打开 document 时重置为 编辑。
  - 编辑模式
      - 下方使用纯文本编辑器按行编辑完整文本，content 是唯一持久化真源。
  - 预览模式
      - 预览规则采用“简化 Markdown + Todo”。
      - 支持的行语法限定为：#/##/### 标题，- [ ] 与 - [x] 待办项，普通文本段落，空行。
      - 预览中显示结构化行列表；标题/段落按样式展示，待办项显示复选框。
      - 预览中的交互范围明确为：勾选完成、插入新待办、删除行、拖拽排序行。
      - 预览交互全部通过“解析 content -> 变更结构 -> 序列化回 content”完成，不引入第二套持久化内容模型。
      - 预览无法识别的复杂 Markdown 行，v1 按普通文本行展示并在序列化时原样保留。

  ## Test Plan

  - 单元测试
      - 文本解析为预览行的正确性：标题、待办、普通文本、空行。
      - 预览行序列化回文本的 round-trip 正确性。
      - 勾选、新增、删除、排序后的文本回写结果。
      - 子文件排序、重命名、删除选择切换逻辑。
      - lastSelectedFileID 的持久化与恢复逻辑，包括目标文件缺失时的回退。
  - UI 测试
      - 新建工作区后可新增子文件并在 Sidebar 选中。
      - 工具栏可在 编辑 / 预览 间切换，内容区同步切换。
      - 编辑模式输入文本后切到预览模式可正确渲染。
      - 预览模式下可勾选任务、插入任务、删除行、拖拽排序，并反映回编辑模式文本。
      - Sidebar 子文件可拖拽排序。
      - 关闭并重新打开 document 后，自动恢复上次选中的子文件；若该子文件已不存在，则回退到第一个可用文件。
  - 验收标准
      - 任意时刻只有一个子文件被编辑/预览。
      - content 始终是单一真源，编辑模式与预览模式之间无内容漂移。
      - 文档重开后，子文件列表、顺序、标题、文本内容，以及上次选中项都能恢复。

  ## Assumptions

  - v1 只支持平铺子文件，不做文件夹树。
  - 子文件标题独立存储，不从正文第一行派生。
  - 预览模式的“全量编辑”限定为勾选、新增、删除、拖拽排序，不包含预览内直接改文字。
  - 复杂 Markdown 特性（代码块、表格、引用、嵌套列表）不纳入 v1；遇到时按普通文本保底。
  - lastSelectedFileID 持久化在当前 document 内，不依赖系统级窗口恢复。
